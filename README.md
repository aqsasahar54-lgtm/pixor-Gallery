# ✦ Pixor Gallery

A modern, responsive and interactive image gallery built with **HTML, CSS and JavaScript**.

Pixor Gallery is designed with a clean and attractive UI where users can explore images by category, search for specific images, and view photos in a fullscreen lightbox.

## ✨ Features

* 🖼️ Modern image gallery layout
* 🔍 Image search functionality
* 🏷️ Category-based image filtering
* 🌙 Dark modern UI
* 🔎 Fullscreen lightbox view
* ⬅️ Previous & Next image navigation
* ❤️ Like button interaction
* ⌨️ Keyboard navigation
* 📱 Fully responsive design
* ✨ Smooth hover effects and transitions
* 🎨 Attractive animations
* 🖥️ Desktop, tablet and mobile friendly

## 🛠️ Technologies Used

* **HTML5** — Website structure
* **CSS3** — Styling, responsive layout, animations and effects
* **JavaScript** — Search, filters, lightbox, navigation and interactions
* **Unsplash** — Image sources

## 🎯 Main Sections

### Hero Section

Introduces Pixor Gallery with a modern visual design and an option to explore the gallery.

### Search

Users can search for images using keywords.

### Categories

Images can be filtered by categories such as:

* Nature
* Travel
* Animals
* Cities
* Space

### Image Gallery

A responsive masonry-style gallery displays the images in an attractive layout.

### Lightbox

Clicking an image opens it in a larger view with:

* Previous button
* Next button
* Close button
* Keyboard navigation
